# India Company Financials Explorer — The Mountain Path Academy
NSE/BSE company statements (₹ crore), ratios, peers, WACC and DCF with a formatted Excel download.
Data: Yahoo Finance (yfinance) for statements and prices; CCIL indicative yields for the 10-year G-Sec risk-free rate. No API key needed.

Run locally:  pip install -r requirements.txt  &&  streamlit run app.py
Deploy: push this folder to a GitHub repo, then share.streamlit.io → New app → app.py.
